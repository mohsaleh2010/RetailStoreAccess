# كشف الحساب ودفتر الأستاذ

## شاشة كشف الحساب (`frmLedger`)
**من أين تُفتح:**
- زر **«كشف حساب»** في **قيود اليومية**.
- زر **«كشف حساب»** في **دليل الحسابات**، فيفتح كشف الحساب المختار مباشرة.

**الاستخدام:**
1. اختر **الحساب**. القائمة مرتبة كشجرة الحسابات، وفيها الحسابات الرئيسية والفرعية.
2. اختر **الفترة**. الافتراضي هذه السنة، ومعها أزرار هذا الشهر والشهر الماضي.
3. تظهر **أربعة أرقام:** رصيد أول المدة، ومدين الفترة، ودائن الفترة، والرصيد الختامي.
   - الرصيد مكتوب **مدين** أو **دائن**.
4. **القائمة:** أول سطر رصيد أول المدة، ثم كل سطر قيد في الفترة بترتيب التاريخ. لكل سطر:
   - التاريخ، ورقم القيد، ونوع العملية، ورقم المستند، والبيان.
   - الحساب الفرعي، والمدين والدائن، و**الرصيد بعد السطر**.

**الحساب الرئيسي** (مثل «النقدية» أو «الأصول المتداولة»):
- يشمل كشفه كل الحسابات التابعة له في كشف واحد.
- عمود «الحساب» يبيّن الحساب الفرعي لكل سطر.

**القيود محدّثة دائمًا:** تُحدَّث عند فتح الشاشة، فيظهر في الكشف كل ما سُجل حتى الآن.

**الأزرار:**

| الزر | العمل |
|---|---|
| **فتح القيد** (أو نقر مزدوج على السطر) | قيد اليومية الكامل |
| **فتح أصل العملية** | الفاتورة، أو السند، أو المصروف، أو القيد اليدوي... |
| **طباعة كشف الحساب** | الكشف على A4: رصيد أول المدة، والأسطر بالرصيد بعد كل سطر، والأرقام الأربعة، وهل الرصيد مدين أو دائن |
| **دفتر الأستاذ** | لكل حساب فرعي تحت الحساب المختار، أو لكل الحسابات إن لم يُختر حساب: رصيد أول المدة، ثم أسطره بالرصيد الجاري، ثم إجمالياته ورصيده الختامي |
| **قيد يدوي** / **دليل الحسابات** | فتح الشاشتين |

## التقارير
| التقرير | من أين | المحتوى |
|---|---|---|
| **كشف حساب** (`rptAccountStatement`) | شاشة كشف الحساب | الحساب المختار، ويشمل الحساب الرئيسي حساباته التابعة |
| **دفتر الأستاذ** (`rptGeneralLedger`) | شاشة كشف الحساب، أو **مركز التقارير ← دفتر الأستاذ (كل الحسابات)** | صفحة لكل حساب فرعي بترتيب الشجرة، ورصيده الجاري يبدأ من رصيد أول المدة لكل حساب |

## الاستعلامات
| الاستعلام | المحتوى |
|---|---|
| `AccountStatementQuery` | سطر رصيد أول المدة، ثم أسطر قيود الحساب وحساباته التابعة في الفترة. المعاملات: `PeriodStart`، `PeriodEnd`، `AccountCode` |
| `qryStatementBefore` | رصيد الحساب قبل الفترة |
| `GeneralLedgerQuery` | لكل حساب فرعي رصيد أول المدة وأسطره. `AccountCode` = 0 لكل الحسابات |

## كيف تحققتُ
| الاختبار | النتيجة |
|---|---|
| كشف حساب العملاء: رصيد أول المدة والمدين والدائن = ميزان المراجعة، والرصيد الختامي 164 | ✅ |
| الحساب الرئيسي (النقدية، الأصول المتداولة، الخصوم، المصروفات) = ميزان المراجعة بالمستويات، والنقدية تشمل صندوقيها | ✅ |
| **الفترة:** قيد الرواتب (3000) داخل الفترة يظهر سطرًا، وقبلها يصبح رصيد أول المدة | ✅ |
| حساب بلا قيود: سطر رصيد أول المدة فقط (صفر) | ✅ |
| **دفتر الأستاذ:** حساب لكل حساب فيه حركة، ولكل منها سطر رصيد أول مدة واحد، ورصيد كل حساب = ميزان المراجعة، وبترتيب الشجرة. والمحصور في «النقدية» يعرض الصندوقين فقط | ✅ |
| **التقريران:** الرصيد الجاري يبدأ من جديد لكل حساب | ✅ |
| `TestJournal` داخل Access: كشف العملاء = رصيد الحساب، وكشف «الأصول» = مجموع كل حسابات الأصول | ✅ مكتوب |
| **لم يُختبر بعد** | التشغيل الفعلي داخل Access |
