# لوحة التحكم الجديدة والإحصائيات بالرسوم البيانية

## لوحة التحكم (`frmMain`)
| الجزء | المحتوى |
|---|---|
| **القائمة الجانبية** | كما هي: كل الشاشات، والزر الباهت لا يملك المستخدم صلاحيته |
| **4 بطاقات رئيسية** بمربع أيقونة ملوّن | مبيعات اليوم (أخضر)، ومبيعات الشهر (أزرق)، وصافي ربح الشهر (أحمر)، والمنتجات منخفضة المخزون (برتقالي). **اضغط البطاقة** لفتح تقريرها |
| **12 مربعًا ملونًا** للشاشات | المبيعات، والمشتريات، والمخزون، والمنتجات، والعملاء، والموردون، والمصروفات، والتقارير، والإعدادات، والمستخدمون، والنسخ الاحتياطي، وتسجيل الخروج. **المربع الرمادي = لا تملك صلاحيته** |
| **4 بطاقات صغيرة** | ديون العملاء، ومستحقات الموردين، وقيمة المخزون، ومصروفات الشهر |
| أسفل الشاشة | سطر فحص سلامة البيانات |

- الترتيب من اليمين لليسار، وتتمدد البطاقات والمربعات مع حجم النافذة.
- القوائم الثلاث السابقة (فواتير اليوم، والنواقص، والأكثر مبيعًا) حُذفت من الشاشة الرئيسية كما في التصميم. بياناتها موجودة في التقارير: المبيعات اليومية، والمنتجات منخفضة المخزون، والإحصائيات.

## تقرير «الإحصائيات والرسوم البيانية» (`rptStatistics`)
من **التقارير** ← «الإحصائيات والرسوم البيانية» ← حدد الفترة ← عرض التقرير، أو PDF.

| الرسم | البيانات |
|---|---|
| **أعمدة: المبيعات الشهرية** لآخر 12 شهرًا تنتهي بشهر نهاية الفترة | `MonthlySalesQuery`: شامل الضريبة بعد المرتجعات، والشهر الحالي باللون الأخضر |
| **دائري: المبيعات حسب التصنيف** مع مفتاح الألوان والنسبة | `SalesByCategoryQuery` (جديد) خلال الفترة. أكبر 8 تصنيفات، والباقي «أخرى» |
| **جدول: أفضل 10 منتجات** مع عمود بياني للمبيعات | `BestSellingProductsQuery` خلال الفترة |

الرسوم تُرسم داخل التقرير نفسه (`modCharts.DrawStatistics` في حدث الطباعة)، بلا أداة رسم بياني خارجية. لذلك تعمل على كل نسخ Access، وتُطبع وتُحفظ PDF بنفس الشكل.
