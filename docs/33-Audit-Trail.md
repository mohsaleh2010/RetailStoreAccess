# سجل التدقيق

**ما يسجّله:** من أضاف أو عدّل أو حذف، ومتى، ومن أي جهاز، وقيمة كل حقل **قبل** التعديل و**بعده**.

## 1) ما الذي يُسجَّل
| المكان | ماذا يُحفظ |
|---|---|
| **كل شاشات البيانات** (المنتجات، العملاء، الموردون، المصروفات، المستخدمون، الحسابات، الإعدادات، الصناديق، البنوك، مراكز التكلفة، المصروفات المتكررة...) | **إضافة:** كل الحقول المعبأة. **تعديل:** الحقول التي تغيّرت فقط، بقيمتها قبل وبعد. **حذف:** السجل كله كما كان |
| **أسطر الموازنة وأسطر مسير الرواتب** | الإضافة والتعديل، بالحقول قبل وبعد |
| **حذف المستندات** | الأصول الثابتة، وقيود الإهلاك، والحركات البنكية، والتسويات البنكية، والشيكات، والقيود اليدوية، ومسيرات الرواتب، والموازنات، ومسودات الإقرار الضريبي. يُحفظ المستند كما كان قبل الحذف |
| **تعديل المستندات** | الأصول الثابتة، والقيود اليدوية، ومسودات الإقرار الضريبي. يُحفظ ما تغيّر |
| **ما كان يُسجَّل سابقًا** | الدخول والخروج، وحفظ الفواتير والسندات، وتغيير الأسعار، والنسخ الاحتياطي... ويظهر الآن في نفس الشاشة |

**كيف تظهر القيم:**
- في القوائم المنسدلة يُحفظ **النص الظاهر** مع رقمه، مثل «نقدي (1)»، لا الرقم وحده.
- التواريخ ميلادية.
- «نعم» أو «لا» للخيارات.

**كلمات المرور لا تُحفظ أبدًا.** يُسجَّل فقط أنها «تغيّرت».

**لا يعطّل العمل:** إذا تعذّر التسجيل لأي سبب، يكمل الحفظ ولا يتوقف المستخدم.

## 2) شاشة سجل التدقيق (`frmAuditLog`)
**من أين تُفتح:**
- **المحاسبة والمالية** ← **سجل التدقيق**؛
- أو **المستخدمون** ← **سجل التدقيق**.

**الصلاحية:** صلاحية جديدة اسمها **«سجل التدقيق»** (`AUDIT_LOG`). تُمنح لمدير النظام فقط افتراضيًا، ويمكن منحها لدور آخر من شاشة الأدوار.

**الاستخدام:**
1. **حدد الفترة:** من، إلى.
2. **صفِّ النتائج (اختياري):**
   - المستخدم؛
   - العملية: إضافة، أو تعديل، أو حذف، أو عمليات المستندات، أو الدخول والخروج؛
   - الجدول؛
   - رقم السجل أو اسمه.
3. **اضغط «عرض»:** تظهر العمليات، الأحدث أولًا، ولكل عملية: الوقت، والمستخدم، والعملية، والجدول، والرقم، والسجل، والجهاز.
4. **اختر عملية:** تظهر حقولها أسفل الشاشة: اسم الحقل، والقيمة **قبل**، والقيمة **بعد**.
5. **«طباعة الفترة»:** تقرير «سجل التدقيق» للفترة، وهو موجود أيضًا في مركز التقارير لمن لديه الصلاحية.

## 3) الجداول (يضيفها `BuildSchema`)
| الجدول / الحقل | المحتوى |
|---|---|
| `AuditLog` | الجدول الموجود: سطر لكل عملية. أُضيف إليه `RecordLabel`، وهو اسم السجل المقروء |
| `AuditChanges` | جديد: حقول كل عملية (اسم الحقل، والقيمة قبل، والقيمة بعد). يُحذف تلقائيًا مع عمليته |

**ملاحظات:**
- السجلات القديمة في `AuditLog` تبقى وتظهر في الشاشة، لكن بلا تفاصيل حقول.
- صار عدد العلاقات 135.

## 4) للمطوّر
- **الكود:** في `modAudit`.
- **شاشات البيانات:** تستدعي `AuditFormBefore` و`AuditFormAfter` تلقائيًا من `modForms`.
- **أي كود جديد يحذف مستندًا يجب أن:**
  1. يأخذ `AuditSnapshot` قبل الحذف؛
  2. يستدعي `AuditDeleted` بعده.

  يوجد اختبار يفحص كل عمليات الحذف. التفاصيل في `AGENTS.md`.
- **عناوين الحقول:** تُقرأ من عنوان الحقل في الشاشة، وإلا فمن عنوان الحقل في ملف البيانات (`Caption` الذي يضعه `BuildSchema`).
