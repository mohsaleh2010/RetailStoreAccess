# طباعة ملصقات الباركود

## ما الذي أُضيف
| العنصر | الوصف |
|---|---|
| شاشة **`frmBarcodeLabels`** (طباعة ملصقات الباركود) | امسح الباركود أو اختر الصنف بالاسم، وحدد **عدد الملصقات**، ثم **معاينة** أو **طباعة**. إضافة نفس الصنف مرة أخرى تزيد عدده. يمكن تعديل العدد أو حذف السطر من الجدول (حتى 500 ملصق لكل صنف) |
| شاشة **`frmLabelSettings`** (إعدادات ملصقات الباركود) | مقاس الملصق، وعدد الملصقات في الصف، والمسافات، والهوامش الأربعة، والطابعة، وارتفاع الباركود، وعرض أرفع خط، وأربعة أسطر نص (سطران أعلى الباركود وسطران أسفله)، والاسم المختصر للمحل، وحجم الخط |
| تقرير **`rptBarcodeLabels`** | ملصق لكل نسخة. قبل كل طباعة يُعاد ضبط التقرير من الإعدادات (`ApplyLabelLayout`) |
| جدول **`LabelSettings`** | سجل واحد للإعدادات، في ملف البيانات |
| الوحدة **`modLabels`** | ترميز الباركود ورسمه، وقائمة الطباعة، والشاشات، واختبار `TestLabels` |

**نوع الباركود:**
- **EAN-13** للباركود المكوّن من 13 رقمًا برقم تحقق صحيح، وهو باركود المنتجات المعتاد.
- **Code 128** لأي كود آخر، مثل كود المنتج `P00021`.
- المنتج الذي لا يحمل باركودًا صالحًا يُطبع بكوده.

**النص أعلى الباركود وأسفله:** لكل سطر من الأسطر الأربعة اختر واحدًا من:
- بدون
- الاسم المختصر للمحل
- اسم المنتج
- السعر (شامل الضريبة، مثل `12.50 ر.س`)
- كود المنتج
- رقم الباركود

## من أين تُفتح
| المكان | الزر | ماذا يضيف |
|---|---|---|
| **فاتورة المشتريات** | «طباعة الباركود» | أصناف الفاتورة الجاري إدخالها، وإن كانت فارغة فآخر فاتورة محفوظة: **ملصق لكل وحدة مشتراة** (الكسور تُقرّب لأعلى) |
| **عرض فاتورة شراء** (من البحث) | «طباعة الباركود» | أصناف تلك الفاتورة بكمياتها |
| **المخزون** | «طباعة باركود» | المنتج المحدد في القائمة (ملصق واحد) |
| **الإعدادات** | «ملصقات الباركود» | يفتح شاشة الإعدادات |
| شاشة الملصقات نفسها | «إعدادات الملصق» | يفتح شاشة الإعدادات |

الصلاحية المطلوبة: **المنتجات** (`PRODUCTS`).

## الإعدادات الافتراضية (طابعة ملصقات حرارية)
- ملصق 38 × 25 مم، وملصق واحد في الصف، والهوامش صفر.
- الباركود بارتفاع 10 مم، وعرض أرفع خط 0.25 مم، وهو مناسب لطابعات 203 نقطة/بوصة.
- **الأسطر:** الاسم المختصر واسم المنتج أعلى الباركود، ورقم الباركود والسعر أسفله، بخط 7.

**ورق A4 فيه ملصقات:**
- اجعل «عدد الملصقات في الصف» مثلًا 3 أو 4.
- أدخل مقاس الملصق الواحد، والمسافة بين الأعمدة والصفوف.
- أدخل هوامش الورقة.

> مقاس **ورق** طابعة الملصقات نفسه (عرض اللفة وطول الملصق) يُضبط مرة واحدة من إعدادات الطابعة في Windows: **Printing preferences ← Page Size**. البرنامج يضبط الهوامش والأعمدة ومقاس الملصق داخل التقرير.

## التثبيت (لمن ثبّت المراحل السابقة)
| # | الخطوة |

| 1 | استورد **`modLabels`** الجديدة، واستبدل المحدَّثة (احذف ثم استورد): `modBuildSchema`، `modBuildForms`، `modBuildReports`، `modForms`، `modAppData`، `modTestAll` |
| 2 | **Debug ← Compile** |
| 3 | `BuildSchema`: يضيف الجدول `LabelSettings` فقط، ولا يلمس البيانات |
| 4 | `BuildForms`، ثم `BuildReports` |
| 5 | `RunAllTests`: المتوقع أن ينجح `TestLabels` مع باقي الاختبارات |

## كيف تحققتُ
| الاختبار | النتيجة |
|---|---|
| مرجع Python للترميز، **وقارئ باركود حقيقي (zxing-cpp)** يقرأ الصورة الناتجة | باركود المنتجات التجريبية العشرون وأكواد أخرى تُقرأ كلها بالنوع الصحيح (EAN-13 أو Code 128) |
| تشغيل كود VBA نفسه عبر LibreOffice | نفس الخطوط حرفًا بحرف لكل العينات (34 عينة)، ومنها النص العربي الذي لا يُرمَّز فيُطبع كود المنتج |
| `TestLabels` داخل Access | الترميز، وتجميع الكميات، وضبط التقرير من الإعدادات، والمعاينة، ومسح القائمة |

**لم يُختبر بعد:** الطباعة الفعلية على طابعة ملصقات. أول ملصق مطبوع امسحه بقارئ المحل. إذا صعبت قراءته فكبّر «عرض أرفع خط» إلى 0.33، أو ارتفاع الباركود.
