# الرواتب (المرحلة الثالثة - الخطوة 2)

## 1) رواتب الموظفين (`frmEmployeePay`)
- **من أين:** زر **«رواتب الموظفين»** في شاشة مسير الرواتب.
- **الصلاحية الجديدة:** `PAYROLL`، لمدير النظام والمدير.
- **من يظهر فيها:** الموظفون أنفسهم (مستخدمو البرنامج). الشاشة **تعدّل بيانات الراتب فقط**، ولا تضيف موظفًا ولا تحذفه. الموظف الجديد يُضاف من شاشة المستخدمين.

**بيانات كل موظف:**

| الحقل | المعنى |
|---|---|
| في مسير الرواتب | يدخل المسير أم لا |
| سعودي | يحدد حصص التأمينات |
| الراتب الأساسي | — |
| بدل السكن | — |
| بدل النقل وبدلات أخرى | — |
| قسط السلفة الشهري | 0 = يُخصم كل رصيد السلف في أول مسير |
| تاريخ التعيين، ورقم الهوية، والآيبان | بيانات مرجعية |

## 2) سلف الموظفين
- **صرف السلفة:** سند صرف نقدية ببند «سلفة موظف»، مع **اختيار الموظف** (حقل جديد إلزامي في السند).
- **سدادها نقدًا:** سند قبض ببند جديد «سداد سلفة موظف»، فيعود المبلغ إلى حساب سلف الموظفين (1600). لا يُقبض أكثر من رصيد سلفه.
- **رصيد سلف كل موظف** = ما صُرف له − ما سدده نقدًا − ما خُصم من مسيراته المرحَّلة.

## 3) مسير الرواتب (`frmPayroll`)
- **من أين:** زر **«الرواتب»** في شاشة القوائم المالية.

**الخطوات:**
1. اختر الشهر، ثم **«إنشاء مسير الشهر»**. تُنشأ **مسودة** فيها سطر لكل موظف نشط «في مسير الرواتب»، بقيمه من بياناته.
   - **خصم السلفة:** القسط، أو كل الرصيد، ولا يتجاوز ما يبقى من راتبه.
2. **عدّل في الجدول:** الإضافي، والمكافآت، وخصم الغياب، وخصم السلفة، والجزاءات، والملاحظات.
   - تُحسب التأمينات والصافي فورًا، ويظهر إجمالي المسير أسفل الجدول.
   - **«إعادة الإنشاء»** يعيد المسودة من بيانات الموظفين.
3. **«ترحيل المسير»:** ينشئ **قيد الرواتب** بتاريخ آخر يوم في الشهر.

   **شروط الترحيل:**
   - لا مبالغ سالبة.
   - الغياب لا يتجاوز الأساسي والسكن.
   - السلفة لا تتجاوز رصيد سلفه.
   - الصافي لا يكون سالبًا.
   - الشهر ليس مقفلًا.

**قيد الرواتب:**

| الحساب | مدين | دائن |
|---|---|---|
| 5500 الرواتب والأجور | الأساسي + السكن − الغياب | |
| 5510 البدلات والحوافز | البدلات الأخرى + الإضافي + المكافآت | |
| 5520 التأمينات الاجتماعية | حصة المنشأة | |
| 2320 التأمينات المستحقة | | حصتا الموظف والمنشأة |
| 1600 سلف الموظفين | | خصم السلف |
| 4200 إيرادات متنوعة | | الجزاءات |
| 2310 رواتب مستحقة | | صافي الرواتب |

4. **«تسجيل الصرف»:** من بنك أو من صندوق، بتاريخ الصرف.
   - **القيد:** 2310 مدين / البنك أو الصندوق دائن.
   - **صرف الصندوق** يظهر في حركته، ولا يتجاوز رصيده.
   - **صرف البنك** يظهر في التسوية البنكية.
5. **سداد التأمينات للمؤسسة:** حركة بنكية «صادر آخر» على الحساب المقابل 2320.

**التصحيح:**
- **«إلغاء الصرف»:** إلا إذا كان مطابقًا في تسوية بنكية.
- **«إلغاء الترحيل»:** لمسير غير مصروف، ولا مسير مرحَّل بعده.
- **«حذف المسودة»:** للمسودة فقط.
- **«طباعة المسير»:** تقرير `rptPayroll`، بالعرض، بإجماليات وتوقيعات.

## 4) التأمينات الاجتماعية (GOSI)
**الأجر الخاضع** = الأساسي + السكن، بحد أعلى قابل للتعديل (الافتراضي 45,000).

| الموظف | حصة الموظف | حصة المنشأة |
|---|---|---|
| سعودي | 9.75% | 11.75% |
| غير سعودي | — | 2% (الأخطار المهنية) |

- **تعديل النسب:** من أسفل شاشة المسير ← «حفظ نسب التأمينات».
  - **راجعها مع المؤسسة:** النسب تتغير بقرارات، ولبعض المشتركين الجدد نسب متدرجة.
  - **المسير المرحَّل يحتفظ بمبالغه.** النسب الجديدة تُطبَّق على المسودات عند تعديلها أو ترحيلها.

## الجداول والحقول الجديدة (يضيفها `BuildSchema`)
| الجدول / الحقل | المحتوى |
|---|---|
| `PayrollRuns` | المسير: الشهر، والحالة (مسودة / مرحَّل)، والصرف |
| `PayrollLines` | سطر كل موظف |
| حقول في `Employees` | الراتب والبدلات، وسعودي، وفي المسير، وقسط السلفة، والهوية، والآيبان، وتاريخ التعيين |
| `CashVouchers.AdvanceEmployeeID` | الموظف صاحب السلفة |
| `Settings` | نسب التأمينات والحد الأعلى للأجر |
| مصادر القيود | `PAYROLL` و`PAYROLL_PAYMENT` |
| حسابات أصبحت أساسية | 2310، 2320، 5500، 5510، 5520 |

## إصلاح في المولّد
- **الخلل:** سطر ثوابت عدد الحقول في `modBuildSchema` تجاوز 1000 حرف، وهو حد سطر VBA.
- **الإصلاح:** الثوابت الطويلة تُقسَّم الآن على عدة أسطر.

## التثبيت
| # | الخطوة |

**ما يفحصه `TestPayroll`:**
- حساب التأمينات والصافي.
- سلفة من سند صرف، ومسودة المسير بقسطها.
- منع الخصم الزائد.
- الترحيل والقيد.
- الصرف من الصندوق، ومنع إلغاء ترحيل مسير مصروف، ثم إلغاء الصرف والترحيل.

كل ذلك داخل معاملة تُلغى.
