# نقطة بيع الكافيهات (شاشة لمس)

اختر من **الإعدادات ← شاشة البيع = الكافيهات (شاشة لمس)**، فيفتح زر **المبيعات** الشاشة **`frmCafePOS`**.

## الشاشة
| الجزء | المحتوى |
|---|---|
| **أعلى: شريط الفئات** | 5 أزرار ملونة في كل صفحة بصورة الفئة، مع «السابقة» و«التالية». فئات الإضافات لا تظهر هنا |
| **وسط: المشروبات والأصناف** | بطاقات أكبر من شاشة المطاعم (5 × 3) فيها الصورة والاسم والسعر |
| **يسار: الطلب** | **سفري** (الافتراضي) أو **محلي**، و**اسم العميل على الكوب** (اختياري)، وأسطر بأزرار − و +، والإجماليات، والدفع نقدي أو بطاقة |

## نافذة المشروب `frmCafeItem`
لمس مشروب **له أحجام** يفتح نافذة فيها:
- **الحجم:** صغير، أو وسط، أو كبير، بأسعارها.
- **الإضافات:** حتى 8 إضافات، مثل حليب شوفان أو شوت إضافي أو كريمة، ويمكن اختيار أكثر من واحدة.
- **ملاحظات:** بدون سكر، أو سكر قليل، أو ثلج قليل، أو ساخن جدًا.
- **الكمية:** بزري + و −، والإجمالي يُحسب فورًا.
- **إضافة للطلب**

الصنف بلا أحجام (كرواسون مثلًا) يُضاف بلمسة واحدة.

## كيف تُحفظ
| في الطلب | في الفاتورة |
|---|---|
| المشروب بحجمه | سطر بسعر الحجم، و**ملاحظة السطر** مثل «كبير، بدون سكر». **سعر الحجم لا يحتاج صلاحية تعديل السعر** |
| كل إضافة | **سطر مستقل** بسعرها (منتج من فئة إضافات)، فتبقى الضريبة والأرباح دقيقة |
| اسم العميل | `SalesInvoices.OrderName`، ويُطبع على الإيصال مع نوع الطلب: «طلب سفري - الاسم: سارة» |
| نفس المشروب بنفس الحجم والملاحظات | يُجمَع في سطر واحد |

## الإعداد
| أين | ماذا |
|---|---|
| **المنتجات** | سعر البيع = **الحجم الصغير**، و«سعر الحجم الوسط» و«سعر الحجم الكبير». وجود أحدهما يجعل للمشروب أحجامًا |
| **التصنيفات** | أنشئ فئة «إضافات» وعلّم **«فئة إضافات»**، وأضف فيها منتجاتها (حليب شوفان 3 ر.س...). ألغِ «يتابع المخزون» للإضافات وللمشروبات المحضّرة |
| الصور والألوان | مثل شاشة المطاعم |

## الحقول الجديدة (يضيفها `BuildSchema` لقاعدتك الحالية)
- `Products`: `SizePriceM` و`SizePriceL`.
- `Categories`: `IsAddOn`.
- `SalesInvoices`: `OrderName`.
- `SalesInvoiceDetails`: `LineNote`.
- جدول السلة المحلي `tmpPOSLines`: عمود `LineNote`، يُضاف تلقائيًا.
