# القوائم المالية: قائمة الدخل والميزانية العمومية

## من أين
| المكان | ماذا يفعل |
|---|---|
| **شاشة القوائم المالية** (`frmFinancials`) | زر «القوائم المالية» في شاشة **كشف الحساب** |
| **مركز التقارير** | «قائمة الدخل» و«الميزانية العمومية» للطباعة مباشرة، أو التصدير PDF / Excel |

- **الصلاحية:** «تقارير الأرباح والضريبة» (`REPORTS_PROFIT`)، لمدير النظام والمدير.
- **القيود محدّثة دائمًا:** تُحدَّث عند فتح الشاشة وقبل الطباعة.

## قائمة الدخل (للفترة من … إلى)
| البند | يأتي من |
|---|---|
| **إيرادات النشاط** ← صافي إيرادات النشاط | حسابات المجموعة 41: المبيعات، مطروحًا منها المردودات والخصم المسموح |
| **تكلفة المبيعات** ← إجمالي تكلفة المبيعات | المجموعة 51: تكلفة البضاعة المباعة، وفروقات المخزون |
| **= مجمل الربح** | صافي الإيرادات − تكلفة المبيعات |
| **المصروفات التشغيلية والإدارية** | المجموعة 52: الإيجار، والكهرباء، والرواتب... |
| **= الربح التشغيلي** | مجمل الربح − المصروفات التشغيلية |
| **إيرادات أخرى** | المجموعة 42، وأي مجموعة إيرادات أخرى تضيفها |
| **مصروفات أخرى** | المجموعة 53، وأي مجموعة مصروفات أخرى تضيفها |
| **= صافي الربح (الخسارة)** | الربح التشغيلي + الإيرادات الأخرى − المصروفات الأخرى |

## الميزانية العمومية (في نهاية الفترة)
- **الأصول:**
  - الأصول المتداولة: كل صندوق، والبنك، والعملاء، والمخزون، وضريبة المدخلات...
  - الأصول غير المتداولة.
  - لكل مجموعة إجمالي، ثم **إجمالي الأصول**.
- **الخصوم:** المتداولة وغير المتداولة، بأرصدتها الدائنة موجبة، ثم **إجمالي الخصوم**.
- **حقوق الملكية:**
  - رأس المال، وجاري المالك، والأرصدة الافتتاحية.
  - **صافي ربح (خسارة) الفترات غير المقفلة**، وهو مجموع الإيرادات ناقص المصروفات حتى تاريخ الميزانية، لأن إقفال السنة لم يُعمل بعد.
- **السطر الأخير: إجمالي الخصوم وحقوق الملكية**، ويساوي إجمالي الأصول.
- **في الشاشة:** يظهر «الفرق»، وهو صفر عند توازن الميزانية.

## عمود المقارنة
كل قائمة فيها عمودان: **الفترة الحالية** و**فترة المقارنة**، ولكل منهما رقم الحساب والمجموع.

| الفترة المختارة | تُقارن بـ |
|---|---|
| شهر كامل، أو هذا الشهر حتى اليوم | نفس الأيام من الشهر السابق |
| هذه السنة (1 يناير حتى اليوم) | نفس التواريخ من السنة الماضية |
| السنة الماضية كاملة | السنة التي قبلها |
| فترة لا تبدأ من أول شهر | نفس عدد الأيام قبلها مباشرة |
| **الميزانية** | تُقارن بالأرصدة في نهاية فترة المقارنة |

## الشاشة
- **الاختيار:**
  - **القائمة:** قائمة الدخل أو الميزانية.
  - **الفترة:** هذا الشهر، أو الشهر الماضي، أو هذه السنة، أو السنة الماضية، أو تاريخان.
- **ثلاثة أرقام رئيسية:**
  - **قائمة الدخل:** صافي الإيرادات، ومجمل الربح، وصافي الربح. الخسارة بالأحمر.
  - **الميزانية:** إجمالي الأصول، والخصوم وحقوق الملكية، والفرق.
- **القائمة كاملة** بترتيب الطباعة.
- **نقر مزدوج على حساب** يفتح **كشف حسابه للفترة نفسها**.
- **طباعة القائمة:** A4 بعمودَي الفترة والمقارنة.

## الاستعلامات
| الاستعلام | المحتوى |
|---|---|
| `IncomeStatementQuery` | أسطر قائمة الدخل بترتيبها: العناوين، والحسابات، والإجماليات، والنتائج |
| `qryIncomeAccounts` | صافي حركة كل حساب إيرادات أو مصروفات في الفترة وفترة المقارنة |
| `BalanceSheetQuery` | أسطر الميزانية بترتيبها: التصنيف، ثم المجموعة، ثم الحسابات، ثم الإجماليات |
| `qryBalanceAccounts`, `qryBalanceItems`, `qryProfitAt` … | أرصدة الحسابات في نهاية الفترة وفترة المقارنة، والربح غير المقفل |
