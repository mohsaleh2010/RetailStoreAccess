# مراكز التكلفة والفروع (المرحلة الثالثة - الخطوة 3)

## 1) المراكز (`frmCostCenters`)
- **من أين:** زر **«مراكز التكلفة»** في دليل الحسابات.
- **الصلاحية:** صلاحية قيود اليومية (`JOURNAL`).
- **بيانات المركز:** رمز واسم، مثل R «التجزئة»، أو M «المطعم»، أو C «المقهى»، أو فرع ثانٍ.
- **المركز الافتراضي:** علّم مركزًا واحدًا «افتراضي». يأخذه كل مستخدم ليس له مركز.
- **مركز كل موظف:** من شاشة **رواتب الموظفين**. على هذا المركز تُسجَّل مبيعاته ومسير راتبه.

## 2) كيف يُوزَّع القيد على المراكز
كل سطر في القيود يحمل مركز تكلفة يأتي من مستند العملية:

| المستند | المركز |
|---|---|
| فاتورة البيع | مركز الكاشير، وإلا المركز الافتراضي |
| مرتجع البيع | مركز الفاتورة الأصلية |
| المصروف | الحقل الجديد «مركز التكلفة» في شاشة المصروفات. فارغ = مركز المستخدم أو الافتراضي |
| سندات النقدية | مركز المستخدم أو الافتراضي (ومصروف سند الصرف معه) |
| الأصل الثابت | الحقل «مركز التكلفة» في شاشة الأصول. إليه يذهب إهلاكه وربح أو خسارة بيعه |
| مسير الرواتب | مركز كل موظف: قيد المسير يُقسم أسطره على المراكز |
| القيد اليدوي | عمود جديد «مركز التكلفة» لكل سطر |
| المشتريات، والمخزون، والبنوك، والشيكات... | بلا مركز (أغلبها حسابات ميزانية) |

**المستندات المسجلة قبل هذه الخطوة تبقى «غير موزعة».** قيودها لا تُعاد، فلا يتأثر شيء في الفترات المقفلة.

## 3) التقارير (مركز التقارير)
- **«قائمة الدخل حسب مركز التكلفة»:** لكل مركز، ومعه «غير موزع»، في الفترة المختارة:
  - الإيرادات.
  - تكلفة المبيعات.
  - مجمل الربح.
  - المصروفات.
  - صافي الربح.
  - **مجموع المراكز = صافي الربح في قائمة الدخل.**
- **«إيرادات ومصروفات كل مركز تكلفة»:** الحسابات تحت كل مركز بمبالغها.
- **في الحالتين:** قيود إقفال السنة مستبعدة، كما في قائمة الدخل.

## الجداول والحقول الجديدة (يضيفها `BuildSchema`)
| الجدول / الحقل | المحتوى |
|---|---|
| `CostCenters` | المراكز |
| `CostCenterID` في `JournalLines` | مركز سطر القيد |
| `CostCenterID` في الفواتير والمرتجعات والمصروفات والسندات والأصول وأسطر المسير وأسطر القيود اليدوية والموظفين | مركز المستند |

## التثبيت
| # | الخطوة |
|---|---|
| 1 | **نسخة احتياطية** |
| 2 | **الأسهل:** أعد تشغيل `dist\tools\BuildFrontEnd.vbs`، فيستورد الوحدة الجديدة `modCostCenters` |
| 3 | **أو يدويًا:** استورد `modCostCenters`. استبدل `modBuildSchema`، `modBuildRelations`، `modBuildQueries`، `modBuildForms`، `modBuildReports`، `modAppData`، `modJournal`، `modSales`، `modCash`، `modForms`، `modPOS`، `modManualEntry`، `modAssets`، `modPayroll`، `modTestAll`. ثم Debug ← Compile، ثم `BuildSchema` ← `BuildRelationships` ← `BuildQueries` ← `BuildForms` ← `BuildReports` |
| 4 | أنشئ المراكز وعلّم الافتراضي، ثم حدّد مركز كل موظف من رواتب الموظفين |
| 5 | **`RunAllTests`:** فيه `TestCostCenters` الجديد |

**ما يفحصه `TestCostCenters`:**
- المركز الافتراضي، وأولوية مركز الموظف عليه.
- أسطر قيد سند نقدية على مركز الموظف.
- ظهور الإيراد في قائمة دخل المركز.

كل ذلك داخل معاملة تُلغى.
