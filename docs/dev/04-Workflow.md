# طريقة العمل والتفكير (لأي مطوّر أو أي ذكاء اصطناعي)

هذا الملف يشرح **كيف يُطوَّر المشروع**: الترتيب، والقرارات، وطريقة التفكير عند الإضافة أو الإصلاح. يصلح مع Claude ومع أي أداة أخرى، مثل ChatGPT/Codex وGemini وCursor وCopilot.
- التعليمات المختصرة لأدوات الذكاء الاصطناعي في [../../AGENTS.md](../../AGENTS.md).
- Claude يقرأ [../../CLAUDE.md](../../CLAUDE.md)، وهو يضم `AGENTS.md`.

## 1) دورة العمل
1. **ميزة واحدة في كل مرة.** يطلبها صاحب المشروع بالعربية، مثل «ابدأ بسجل التدقيق».
2. **الفهم قبل الكتابة:**
   - اقرأ وثيقة الميزة القريبة في `docs/NN-*.md`.
   - اقرأ الجداول المعنية في `tools/schema.py`.
   - اقرأ أقرب ميزة مشابهة وانسخ نمطها. أمثلة: `modBudget` و`modRecurring` و`modAudit`، و`forms_budget.py` و`forms_audit.py`.
3. **التنفيذ بالترتيب:**
   1. الجداول؛
   2. الاستعلامات؛
   3. الشاشات والتقارير؛
   4. منطق VBA في وحدة مكتوبة يدويًا؛
   5. اختبار داخل Access `TestX`؛
   6. اختبارات Python؛
   7. الوثيقة.
4. **التوليد والاختبار:** `python3 tools/generate.py` ثم `python3 -m unittest discover -s tests`، حتى تنجح كل الاختبارات.
5. **المراجعة:** راجع التغييرات مقابل «قواعد Access» في القسم 3 أدناه.
6. **الوثائق مع كل تعديل:**

   | ما تغيّر | الوثيقة التي تُحدَّث |
   |---|---|
   | ميزة جديدة | `docs/NN-Name.md` جديد، وسطر في `README.md` بحالة «بانتظار الموافقة» |
   | تعديل على ميزة | وثيقتها |
   | قاعدة جديدة تعلمناها | `AGENTS.md`، وهذا الملف |
   | الجداول، والشاشات، والبنية | الملفات في `docs/dev/` |

   المراجع المولَّدة تتحدث وحدها مع `generate.py`.
7. **الحفظ:** commit برسالة إنجليزية واضحة، ثم push إلى الفرع. لا Pull Request إلا بطلب، ولا اسم نموذج ذكاء اصطناعي في أي ملف.
8. **تقرير بالعربية، ثم انتظار الموافقة:**
   - ما الذي أُضيف، والمشكلات وحلولها؛
   - الوحدات التي تُستورد أو تُستبدل، وأوامر Build بالترتيب، أو «شغّل `BuildFrontEnd.vbs` من جديد»؛
   - طريقة الاختبار: `TestX` و`RunAllTests` وخطوات يدوية؛
   - اقتراح الخطوة التالية.

## 2) طريقة التفكير في القرارات
- **البيانات الموجودة عند العميل مقدسة.**
  - كل تغيير في الجداول يجب أن يعمل على ملف بيانات قديم.
  - الحقل الجديد اختياري أو له قيمة افتراضية.
  - المستندات القديمة تبقى كما هي، فتوقيع القيد لا يتغير لمستند قديم.
- **لا تخزين لما يمكن حسابه:** الأرصدة تُحسب من الحركات. الحقل المساعد يُحدَّث في نفس المعاملة.
- **المستند لا يُعدَّل بعد الحفظ:** التصحيح بمستند عكسي. ما يقبل التعديل، مثل المسودات، يُسجَّل تعديله في سجل التدقيق.
- **الفترة المقفلة لا تُمس:** فحص `ClosedPeriodProblem` في كل حفظ أو حذف له تاريخ.
- **الصلاحية قبل العملية:** `HasPermission` أو `CanScreenAction`، والرسالة بالعربية.
- **الرسائل للمستخدم بالعربية:** واضحة وتقول ماذا يفعل. الكود والتعليقات بالإنجليزية.
- **عند الشك في قرار تجاري** (محاسبي أو ضريبي): اسأل صاحب المشروع سؤالًا واحدًا واضحًا قبل الكتابة.

## 3) قواعد Access وVBA (كل قاعدة كانت خطأ حقيقيًا)
لا توجد أداة ترجمة لـ Access في بيئة التطوير، لذلك تُحترم هذه القواعد يدويًا وتفحصها الاختبارات:

| القاعدة | الخطأ الذي سببته |
|---|---|
| VBA ينفّذ **طرفي `And`/`Or`** و**فرعي `IIf`** دائمًا. لا تكتب `IsDate(x) And DateValue(x)` ولا `IIf(IsNull(x), …, SqlDate(x))` | Type mismatch و Invalid use of Null (إعادة فتح الفترة) |
| إجراء `Private` لا يُستدعى من وحدة أخرى | Sub or Function not defined (فشل الترجمة) |
| لا اسم متغير يطابق دالة أو كلمة محجوزة: `left` و`month` و`line` و`text` و`now` و`dir` و`sub`، ولا اسم `Public` مكرر في وحدتين | أخطاء ترجمة أو نتائج خاطئة |
| `If … End If` كتلة كاملة بدل السطر الواحد مع `Else`. ولا تستخدم `Switch()` | أخطاء ترجمة |
| السطر أقل من 1000 حرف، وأقل من 24 سطر استمرار `_` | Line too long |
| أحرف Windows-1256 فقط في VBA | نص مشوّه |
| خاصية لا يملكها نوع العنصر، مثل `BackColor` لمربع الاختيار | خطأ 438 |
| اسم عمود فارغ `AS [ ]` | خطأ 3126 |
| أكثر من 32 فهرسًا في جدول (العلاقة تُحسب على الطرفين) | خطأ 3626 |
| الجدول المؤقت بلا قيم افتراضية: اكتب 0 صراحة | مجاميع Null |
| شرط جدول على عمود يجب أن يسمح بما يحتاجه الكود، مثل صافي راتب سالب في المسودة | رفض الحفظ برسالة غير مفهومة |
| شاشتان على جدول واحد: افحص `frm.Name` | خطأ 2465 |
| لا `CurrentDb.TableDefs(...).Fields` متسلسلة. خزّن `CurrentDb` في متغير أولًا | خطأ 3420 |
| SQL في Access: لا تستخدم الاسم المستعار داخل تعبيره، وكل فرع `UNION` له `FROM`، ولا استعلام فرعي في أعمدة مصدر تقرير بمجاميع | أخطاء استعلامات |
| التقويم: `Calendar = vbCalGreg`، والعرض بـ `GDate` | تواريخ هجرية في أجهزة سعودية |

## 4) تشخيص خطأ يأتي من Access
1. **اطلب الدليل الكامل:**
   - نص الرسالة؛
   - السطر الذي يظهر بعد Debug، واسم الوحدة؛
   - `BuildFrontEnd.log` أو `RunAllTests.log`.
2. **حدد المكان:**
   - خطوة البناء؛
   - أو الشاشة؛
   - أو رقم الفحص في الاختبار: عُدّ الفحوص بعد آخر فحص نجح.
3. **ابحث عن السبب الجذري**، لا عن العَرَض. ثم ابحث عن **نفس النمط** في كل الكود وأصلحه.
4. **أضف اختبارًا يفشل بدون الإصلاح**، وتأكد من ذلك فعليًا.
5. **أضف القاعدة** إلى القسم 3 في هذا الملف، وإلى `AGENTS.md`.
