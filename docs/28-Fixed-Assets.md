# الأصول الثابتة والإهلاك (المرحلة الثالثة - الخطوة 1)

## 1) شاشة الأصول الثابتة (`frmAssets`)
- **من أين:** زر **«الأصول الثابتة»** في شاشة القوائم المالية.
- **الصلاحية الجديدة:** `FIXED_ASSETS`، لمدير النظام والمدير.

**بيانات الأصل:**

| الحقل | المعنى |
|---|---|
| اسم الأصل | — |
| حساب الأصل | المجموعة: الأثاث 1710، الأجهزة 1720، السيارات 1730، الديكورات 1740، البرامج 1800، أو أي حساب فرعي تضيفه تحت 12 |
| تاريخ الشراء | — |
| التكلفة بدون الضريبة | — |
| ضريبة المدخلات | — |
| القيمة المتبقية | ما يساويه الأصل في آخر عمره |
| العمر الإنتاجي | بالأشهر |
| بداية الإهلاك | يُهلك من شهرها |

**مصدر الشراء وقيده** (قيد «اقتناء أصل ثابت» بتاريخ الشراء):

| المصدر | القيد |
|---|---|
| من البنك | حساب الأصل وضريبة المدخلات (1500) مدين / البنك دائن |
| من صندوق | مثل البنك، والصندوق دائن. ويظهر في حركة الصندوق كخارج، ولا يُدفع أكثر من رصيده |
| على حساب آخر | مثل البنك، والحساب الآخر دائن (مثلًا 2300 مستحقات، 2500 قرض، 3100 جاري المالك). لا يكون صندوقًا ولا بنكًا ولا العملاء أو الموردين |
| موجود قبل البرنامج | حساب الأصل مدين بالتكلفة / مجمع الإهلاك (1790) دائن بالإهلاك السابق / الأرصدة الافتتاحية (3900) دائن بالباقي. بلا ضريبة |

- **أعلى القائمة:** رقم الأصل، ومجمع الإهلاك، والقيمة الدفترية، والقسط الشهري، وعدد الأشهر المسجلة.
- **التعديل والحذف:** لأصل لم يُسجَّل عليه إهلاك ولم يُستبعد، وفي فترة مفتوحة.
- **«طباعة السجل»:** تقرير **سجل الأصول الثابتة** (`rptFixedAssets`). يوجد أيضًا في مركز التقارير.

## 2) الإهلاك الشهري (`frmDepreciation`)
- **الطريقة:** القسط الثابت. القسط الشهري = (التكلفة − القيمة المتبقية) ÷ العمر بالأشهر، مقربًا لهللتين.
- **حدود القسط:**
  - لا ينزل الأصل عن قيمته المتبقية.
  - إذا بقي أقل من ريال بعد قسط الشهر، يؤخذ الباقي كله في هذا الشهر، حتى لا تبقى هللات التقريب.
- **أشهر الإهلاك:**
  - يبدأ من شهر «بداية الإهلاك».
  - **لا يُهلك** الأصل في شهر بيعه أو استبعاده، ولا بعده.
- **القيد:** قيد «الإهلاك الشهري» بتاريخ آخر يوم في الشهر. لكل أصل سطران: مصروف الإهلاك (5600) مدين / مجمع الإهلاك (1790) دائن.

**الشاشة:**
- تعرض **الشهر التالي** المطلوب تسجيله، وإهلاك كل أصل فيه، والإجمالي.
- **«تسجيل الإهلاك حتى هذا الشهر»:** يسجل كل شهر لم يُسجَّل، **بالترتيب**.
  - الشهر يُسجَّل في آخر يوم منه أو بعده، وليس في فترة مقفلة.
- **«حذف آخر شهر»:** لآخر قيد فقط، في فترة مفتوحة، ولا يكون فيه أصل استُبعد بعده.

## 3) البيع أو الاستبعاد
**الطرق:**
- **بيع:** الثمن في البنك أو في صندوق. يظهر في حركة الصندوق كداخل.
- **استبعاد بدون ثمن:** للتلف أو الفقد.

**القيد** (قيد «بيع أو استبعاد أصل ثابت» بتاريخ البيع):

| الحساب | مدين / دائن |
|---|---|
| مجمع الإهلاك (1790) | مدين بإهلاك الأصل حتى يومه |
| البنك أو الصندوق | مدين بالثمن |
| حساب الأصل | دائن بالتكلفة |
| الفرق | **ربح** في 4500 «أرباح بيع الأصول الثابتة»، أو **خسارة** في 5650 «خسائر بيع واستبعاد الأصول الثابتة» |

- **شرط الاستبعاد:** ألا يكون للأصل إهلاك مسجل من شهر الاستبعاد أو بعده.
- **«إلغاء الاستبعاد»:** متاح في فترة مفتوحة.
- **ضريبة المخرجات** على بيع الأصل لا يحسبها البرنامج. إن كان البيع خاضعًا، سجّلها بقيد يدوي وأضفها في تصحيحات الإقرار.

## الجداول والحسابات
| الجدول / الحساب | المحتوى |
|---|---|
| `FixedAssets` | الأصل، ومصدر شرائه، والإهلاك السابق، وبيانات البيع أو الاستبعاد |
| `DepreciationRuns` و`AssetDepreciations` | قيد إهلاك كل شهر وأسطره لكل أصل |
| مصادر القيود | `ASSET` و`ASSET_DISPOSAL` و`DEPRECIATION` |
| حسابات جديدة | 4500 أرباح بيع الأصول، 5650 خسائر بيع واستبعاد الأصول |
| حسابات أصبحت أساسية | 1790 مجمع الإهلاك، 5600 مصروف الإهلاك |

## البيانات التجريبية
- **الأصل التجريبي:** «أجهزة نقاط البيع وطابعات الإيصالات»، موجود قبل البرنامج.
- **قيمه:** تكلفة 6,000، وإهلاك سابق 1,500، وعمر 36 شهرًا، وقيمة متبقية 600.
- **أثره:** قيود البيانات التجريبية زادت قيدًا واحدًا، و`VerifyDemoData` يفحص ذلك.

- إهلاك ثلاثة أشهر بالترتيب، ومنع تعديل تكلفة أصل عليه إهلاك.
- الاستبعاد بخسارة، ومنع حذف قيد فيه أصل مستبعد.
- إلغاء الاستبعاد، وحذف آخر شهر، وتوازن القيود.
